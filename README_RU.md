# Реальный сайт «Склад — учёт мешков»

Это уже не HTML-файл: это веб-приложение с сервером и общей базой SQLite.

## Запуск на сервере

Нужен сервер/хостинг с Node.js 20+.

```bash
npm install
npm start
```

После запуска сайт будет доступен по адресу сервера.

## Что умеет

- Поиск по Чувал №, Баркоду или Фиш №.
- Добавление на Склад 1/2/3.
- Загрузка TXT/CSV со сканера.
- При выдаче склад выбирать не нужно: сервер сам ищет баркод среди всех трёх складов.
- История операций.
- Выгрузка всей базы CSV.
- Общая серверная база, поэтому данные не привязаны к одному телефону.

### Формат данных сканера

Поддерживается:

`Баркод | Чувал № | Фиш № | Дата | Код | Имя | KG`

или просто один баркод в строке.

## Важно

Для постоянного хранения базы папка `data` должна находиться на постоянном диске хостинга.
